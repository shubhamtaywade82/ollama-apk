Hearth 是一款私密的 Ollama 聊天客户端。它连接你自己的电脑或服务器、局域网中的服务器，或 Ollama Cloud 上的模型。Hearth 不会在手机上运行模型，因此你需要一台 Ollama 服务器或一个 Ollama Cloud 账户。

主机与可靠性
- 添加多台 Ollama 服务器，按优先级排序，并通过实时健康检查查看哪些在线。
- 如果当前主机在回复开始前停止响应，下一台健康的主机会自动接管。

Ollama Cloud
- 使用 Ollama Cloud API 密钥登录。密钥保存在 Android Keystore 支持的存储中，且只通过 HTTPS 发送至 ollama.com。
- 用量页面显示花费、令牌数、按模型的明细以及剩余额度。

模型
- 查看已安装的模型、已加载的模型及其占用的内存，并可在同一页面卸载或删除模型。

聊天
- 支持 Markdown 的流式回复、多个对话，以及面向视觉模型的图片输入。
- 推理模型会把思考过程流式显示在回答上方的可折叠区域中。
- 可在消息中附加文件和 PDF。
- 可复制、朗读或重新生成任意回复。
- 语音模式，支持语音转文字和文字转语音。

智能体工具（可选）
- 只有报告支持工具的模型才会获得工具。
- 网页搜索和网页抓取通过 Ollama Cloud 完成。
- 只读的 Binance 价格和K线数据。Hearth 从不下单。
- 远程 MCP 服务器（Streamable HTTP，可选 Bearer 令牌）可以添加工具。请只添加你信任的服务器。

聊天记录保存在应用数据文件中，而不是普通偏好设置里。
